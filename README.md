# Генерация QR-кода для оплаты по банковским реквизитам

Этот проект представляет собой веб-приложение для генерации QR-кодов, которые можно использовать для оплаты по банковским реквизитам. QR-коды совместимы с банковскими приложениями, такими как Сбербанк, Тинькофф, ВТБ и другие. Формат строки — ГОСТ Р 56042-2014 (ST00012), «оплата по реквизитам» (это не протокол СБП-эквайринга, а универсальный формат, который читают банковские приложения при сканировании квитанций).

## Функциональность

- **Генерация QR-кода**: на основе введённых данных формируется QR-код, который можно отсканировать в банковском приложении.
- **Валидация реквизитов**: проверка контрольной суммы ИНН (10/12 цифр), формата БИК и контрольного числа расчётного/корреспондентского счёта относительно БИК (мягкое предупреждение, не блокирует работу).
- **Сумма прописью**: сумма платежа автоматически показывается словами (рубли и копейки), поддерживается ввод копеек через точку/запятую.
- **Позиции счёта**: можно расписать счёт по строкам (наименование, кол-во, цена) — сумма и QR обновятся автоматически.
- **Счёт на оплату**: печать и сохранение в PDF через диалог печати браузера — отдельный печатный шаблон с реквизитами, позициями, суммой прописью, QR-кодом, местом для подписи руководителя и печати организации.
- **Подпись и печать**: можно один раз загрузить изображение подписи и печати — они будут подставляться на все счета.
- **Скачивание QR как PNG** и, если поддерживает браузер/устройство, **«Поделиться»** через системное меню.
- **Сохранение шаблонов**: сохранение введённых данных в браузере, экспорт/импорт шаблонов в JSON-файл (для переноса между браузерами/устройствами или резервной копии).
- **Тёмная тема** с сохранением выбора.
- **Офлайн-режим (PWA)**: приложение можно установить на телефон/компьютер, работает без интернета после первого открытия.
- **Адаптивный дизайн**: корректно отображается как на настольных компьютерах, так и на мобильных устройствах.

## Использование

1. Откройте файл `index.html` в браузере (или установленное PWA-приложение).
2. Заполните форму с банковскими реквизитами:
   - Наименование получателя платежа (обязательно)
   - ИНН получателя, КПП
   - Номер расчётного счёта (обязательно)
   - Наименование банка (обязательно), БИК (обязательно)
   - Номер кор./сч. банка (обязательно)
   - Плательщик (для счёта), назначение платежа
   - Сумма платежа — вручную или как сумма позиций счёта
3. QR-код автоматически сгенерируется на основе введённых данных.
4. Нажмите «Печать / Скачать PDF», чтобы получить счёт на оплату с QR-кодом, подписью и печатью.
5. Для сохранения данных в браузере введите название/тег и нажмите кнопку «Сохранить результат». Сохранённые данные отображаются в разделе «Сохранённые результаты», откуда их можно загрузить, удалить, экспортировать или импортировать.

## Технологии

- **HTML/CSS**: для структуры и стилей страницы, включая печатную вёрстку и тёмную тему.
- **JavaScript**: для обработки данных формы, валидации, генерации QR-кодов, суммы прописью и работы с локальным хранилищем.
- **Библиотека QRCode.js**: для создания QR-кодов.
- **Service Worker + Web App Manifest**: для офлайн-режима и установки как приложение (PWA).

## Приватность

Ничего не отправляется на сервер — все данные, включая шаблоны, подпись и печать, хранятся только в localStorage вашего браузера. Кнопка «Очистить все сохранённые данные» удаляет их безвозвратно.

## Установка

1. Склонируйте репозиторий или загрузите файлы проекта.
2. Откройте файл `index.html` в любом современном браузере.
